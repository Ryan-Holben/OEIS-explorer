# Design Exploration Demos

This folder contains demo pages used during the design system development process.

## Files

### DesignExploration.tsx / DesignExploration.css
**Purpose:** Interactive demo page for exploring design choices

**Features:**
- Font selection (8 professional fonts)
- Color palette selector (8 accent colors)
- 6 different color accent concepts:
  1. Pure Minimal - functional color only
  2. Left Accent Border - bookmark-style left border
  3. Underlined Section Headers - colored underline
  4. Thin Top Border Stripe - top border
  5. Accent Dots - small colored circles
  6. Subtle Combination - mixed approach

**Usage:** This was used to finalize design decisions with stakeholders. Preserved for reference.

**Date Created:** October 28, 2025

---

## Running Demos

These demos are standalone components. To view them:

1. Temporarily import and render in `App.tsx`
2. Or create a separate route for design demos

**Note:** These are not part of the production application.
